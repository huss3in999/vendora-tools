# SEO and Google Indexing Plan

This project can be indexed for free through Google Search Console and a clean technical SEO foundation.

## Public URLs to Index

- Main app landing page: `https://smart.getvendora.net/`
- Published customer pages: `https://smart.getvendora.net/p/<short-code>`
- Sitemap: `https://smart.getvendora.net/sitemap.xml`
- Robots file: `https://smart.getvendora.net/robots.txt`

Private dashboards are intentionally blocked from search:

- `/app`
- `/admin`
- `/login`
- `/signup`

## Free Google Indexing Steps

1. Add `smart.getvendora.net` as a URL-prefix property in Google Search Console.
2. Verify the property using the DNS or HTML meta-tag method.
3. Submit this sitemap:

   `https://smart.getvendora.net/sitemap.xml`

4. Use URL Inspection for:

   `https://smart.getvendora.net/`

5. Request indexing for important published pages, for example:

   `https://smart.getvendora.net/p/hussain`

## Page Owner SEO Rules

Published pages can be indexed when:

- The page status is `published`.
- The page has an active short link.
- `allow_indexing` is enabled.
- The page is included in `sitemap.xml`.

Draft, archived, unpublished, or indexing-disabled pages should not be indexed.
