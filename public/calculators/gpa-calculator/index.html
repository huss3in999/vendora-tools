Guide: GPA Calculator

What it does

This tool converts course letter grades into grade points, applies credits, and estimates a semester GPA.

How to use it

Add each course, choose its letter grade and credits, then select weighted mode if your school gives extra points for advanced courses.

Formula

GPA = sum(grade points x credits) / sum(credits).

Example

An A in a 3-credit class and a B in a 3-credit class gives (4 x 3 + 3 x 3) / 6 = 3.50 on a 4.0 scale.

FAQs

What is the difference between weighted and unweighted GPA?

Unweighted GPA uses the base grade points only. Weighted GPA can add a bump for honors, AP, IB, or advanced classes.

Does this replace my school's official GPA?

No. Schools can use different grading scales and rules, so this calculator is only a practical estimate.

How are credits used in the GPA calculation?

Each course grade point is multiplied by its credits, then divided by total credits to produce a weighted average.
