# Vendora PDF Converter Lab

This folder is an isolated lab for improving PDF to Word, Excel, and PowerPoint conversion.

The live website PDF tools must not be edited during lab work. This lab exists so diagnosis, experiments, reports, and future converter prototypes can happen safely without changing the current public tools.

## Purpose

The first goal is diagnosis, not conversion. PDF samples should be placed into the fixture folders so each document type can be studied separately before any converter logic is added.

Later phases can add real DOCX, XLSX, and PPTX generation, plus repeatable tests that compare actual output against expected gold-standard files.

## Folder Guide

- `fixtures/01-simple-text/`: Simple text PDFs with normal paragraphs and headings.
- `fixtures/02-invoice/`: Invoice PDFs with totals, line items, dates, and business details.
- `fixtures/03-table-bordered/`: Tables with visible borders and grid lines.
- `fixtures/04-table-borderless/`: Tables that rely on spacing instead of visible borders.
- `fixtures/05-arabic/`: Arabic-only PDFs for RTL text and font handling.
- `fixtures/06-mixed-arabic-english/`: Mixed Arabic and English PDFs for bidirectional text testing.
- `fixtures/07-scanned-ocr/`: Scanned or image-only PDFs that require OCR.
- `fixtures/08-images-heavy/`: PDFs with many images, logos, stamps, or graphics.
- `fixtures/09-multi-column/`: PDFs with newsletters, reports, or multi-column reading order.
- `fixtures/10-presentation-style/`: Slide-like PDFs intended for PowerPoint-style output.
- `fixtures/11-forms/`: PDFs with form fields, labels, checkboxes, or structured input areas.
- `fixtures/12-broken-edge-cases/`: Damaged, unusual, encrypted, rotated, or difficult PDFs.

## Output Areas

- `reports/`: Generated diagnosis reports will go here.
- `actual/`: Converted files generated by experiments will go here.
- `expected/`: Expected or gold-standard files will go here for comparison.

## Safety Rule

Do not edit the live PDF converter pages or assets while working in this lab. Keep all experiments inside `tools/pdf-converter-lab/`.
