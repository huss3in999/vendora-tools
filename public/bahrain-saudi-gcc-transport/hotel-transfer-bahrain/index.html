خيارات توصيل الفندق

المطار إلى الفندق

تأكيد صالة الوصول ونقطة اللقاء قبل موعد الرحلة.

الفندق إلى المطار

اختيار وقت الاستلام بما يناسب موعد المغادرة والمسافة.

الفندق إلى موعد

اجتماع أو مطعم أو معلم مع توصيل مباشر أو عودة حسب الاتفاق.

عدة فنادق أو توقفات

يجب ذكر كل توقف مسبقاً حتى يتم تأكيد الوقت والسعر.

معلومات الحجز

  • اسم الفندق والعنوان أو رابط الموقع.
  • التاريخ والوقت ورقم الرحلة عند الحاجة.
  • أسماء نقاط الالتقاء إذا كان الفندق كبيراً.
  • الركاب والأطفال والأمتعة.
  • اتجاه واحد أو عودة.

قد تختلف سياسة الانتظار عند تأخر الرحلة أو تأخر الخروج من الفندق، وتؤكد مع الحجز.
