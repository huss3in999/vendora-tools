# New Page Checklist

Use this checklist before saving any new Vendora page, tool, calculator, PDF tool, transport page, or content page.

- [ ] Page created in the correct folder.
- [ ] URL planned and does not conflict with an existing URL.
- [ ] Unique title added.
- [ ] Meta description added.
- [ ] Canonical added.
- [ ] Robots index/follow added unless private.
- [ ] Open Graph title and description added.
- [ ] Twitter title and description added.
- [ ] Visible H1 added.
- [ ] Quick answer, intro, or short summary added.
- [ ] Internal links added to relevant hub/category/sibling pages.
- [ ] Schema JSON-LD added if suitable.
- [ ] FAQ schema added only if visible FAQ exists.
- [ ] Sitemap updated.
- [ ] `sitemap-tools.xml` updated if this is a tool or calculator.
- [ ] `data/tools-catalog.json` updated if this is a tool or calculator.
- [ ] `llms.txt` updated if important.
- [ ] `.well-known/llms.txt` updated if it mirrors `llms.txt`.
- [ ] `ai-index.json` updated if important.
- [ ] Relevant hub or category page updated.
- [ ] GA/global tracking confirmed.
- [ ] Existing analytics event pattern followed if similar pages use one.
- [ ] No duplicate GA script added.
- [ ] Microsoft Clarity or other existing tracking preserved if present.
- [ ] No private/admin/API/test URL indexed.
- [ ] No fake reviews added.
- [ ] No `AggregateRating` added unless real eligible reviews exist.
- [ ] No hidden SEO text or keyword stuffing added.
- [ ] Page tested locally.
- [ ] No existing URL broken.
